DAY 21 - PORTSWIGGER SQL INJECTION LAB
=======================================

Lab:
SQL injection vulnerability allowing login bypass

Target:
Authorized PortSwigger Web Security Academy training lab

Tool:
Burp Suite

Test sequence:
1. Opened the assigned SQL injection training lab.
2. Submitted a normal login request and captured it in Burp Suite.
3. Sent the login request to Burp Repeater.
4. Modified the username parameter to:
   administrator'--
5. Sent the modified request.
6. Burp returned:
   HTTP/2 302 Found
   Location: /my-account?id=administrator
7. The response also set a session cookie.

Observed result:
The application accepted the modified login request and returned a redirect
to the administrator account endpoint, demonstrating the SQL injection
login-bypass behavior in the authorized training environment.
