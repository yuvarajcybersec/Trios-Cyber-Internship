## Day 01 — Kali Linux & Network Setup

The first task focused on establishing and documenting a Kali Linux lab environment and performing basic system and network enumeration.

### Activities Performed

- Verified the Kali Linux hostname
- Identified the current user
- Enumerated network interfaces and IP addresses
- Reviewed network configuration using `ifconfig`
- Identified the default gateway and routing table
- Tested connectivity to the local gateway
- Tested external network connectivity
- Enumerated listening TCP/UDP services
- Captured screenshots and preserved command outputs as evidence

### Key Findings

- **Hostname:** `kali`
- **Primary Interface:** `eth0`
- **Lab/Attacker IP:** `10.0.2.15/24`
- **Default Gateway:** `10.0.2.2`
- **Network:** `10.0.2.0/24`
- **Listening Services:** No listening sockets reported during enumeration
